مراقب الشبكة - حزمة تحديث تجريبية
================================

الملفات:
- index.html: واجهة مراقبة الشبكات الحالية مع تسجيل العملاء والتحقق من OTP.
- admin.html: لوحة مالك مستقلة لإدارة الشبكات والحسابات ورموز واتساب.
- api/[...route].js: واجهة API والصلاحيات.
- package.json: اعتماديات Node.js.

النشر:
ضع محتويات هذا المجلد داخل مجلد src في مشروع shabakah-monitor (أي أن index.html وadmin.html وpackage.json وapi/ تكون داخل src).

المتغيرات المطلوبة في Vercel:
- DATABASE_URL
- JWT_SECRET
- ROUTER_ENCRYPTION_KEY (مفتاح hex بطول 64 خانة)
- AGENT_SHARED_SECRET

OWNER_INITIAL_PASSWORD اختياري؛ إن لم يُضبط فستكون كلمة المرور الأولية للمالك 7894123 واسم المستخدم salem. غيّر كلمة المرور فور أول دخول من /admin.html.

لوحة المالك: /admin.html
واجهة المستخدمين: /

ملاحظات أمنية:
- رمز OTP مشفر في قاعدة البيانات ويُعرض للمالك فقط داخل لوحة المالك حتى يرسله يدوياً عبر واتساب.
- لا يوجد إرسال تلقائي أو اتصال بواجهة WhatsApp Cloud API.
- رمز الدخول صالح لخمس دقائق ولمرة واحدة، مع حد أقصى لخمس محاولات وطلب رمز جديد بعد دقيقة.
- صلاحيات الشبكات تُفحص من الخادم، وليس من الواجهة فقط.
- تم الإبقاء على جداول الشبكات والمنافذ والأجهزة والأعطال والوكيل وتشفير كلمة مرور الراوتر.

الفحوص التي أُجريت محلياً:
- node --check على ملف API.
- استخراج JavaScript من index.html وadmin.html وفحصه بـ node --check.

هذه حزمة مراجعة/اختبار وليست منشورة على الإنتاج. لم يتم تغيير النشر الحالي أو قاعدة البيانات في هذه الخطوة.
